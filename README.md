# EJ’s Rock Band Jams

Mobile-friendly GitHub Pages song catalog.

## Included

- 660 songs
- 436 artists
- Instant artist/song search
- A–Z browsing
- Artist and song views
- Random-song button
- No database or build process

## Publish

1. Create a public GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.

Your URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Update the catalog

Edit `songs.js`. Each entry uses:

```js
{ "artist": "Linkin Park", "title": "Crawling" }
```
GitHub Pages deployment enabled.
